Iradi letters in Windows 8

04 November 2012 · windows

Windows 8 is out and of course there is no Iradi keyboard. Here is what works:

  • Add the Turkish (Q) layout: it has ü, ö, ı, ç, ş, ğ in the right places.

  • For ñ use Alt+0241, or install the old Attelkom Iradi layout from the CD (it still installs, ignore the warning).

  • Switch layouts with Win+Space.

Tested on three laptops at my cousin's office. Two worked, the third was not Windows 8, it was a very old Windows 7 that he called Windows 8.
